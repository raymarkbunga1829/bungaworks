# Bungaworks

Indie studio site for **Ray Mark Bunga** (Davao). Ships **STACK** — a guideline Tetris with 7-bag, SRS wall kicks, lock delay, ghost, hold, and a next-5 queue.

## Play

- [Play STACK](/play)
- [Journal](/journal)
- [Studio](/studio)

Keyboard: A/D or arrows move · Z/X rotate · S soft drop · space hard drop · C/Shift hold · Esc pause.

## Stack

React 19, TanStack Start, Vite, Tailwind. The well is a canvas 2D engine. Signed-in runs can land on the studio board.

## Deploy

Import this repo on Vercel. Framework is detected from `vite.config.ts` (Nitro `vercel` preset on build). Build command: `npm run build`.
